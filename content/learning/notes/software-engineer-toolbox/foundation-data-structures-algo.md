---
title: "Foundational Data Structures & Algorithms"
---

Know the costs, invariants, and practical uses of the following—not only how to
implement them in an interview.

## Data structures

- Arrays, dynamic arrays, strings, bitsets, and matrices.
- Linked lists, stacks, queues, deques, ring buffers, and priority queues/heaps.
- Hash maps/sets: hashing, collisions, resizing, equality/hash-code contracts, and iteration order.
- Trees: binary search trees, traversals, heaps, tries, and prefix search.
- Graphs: adjacency list/matrix representations, directed/undirected and weighted graphs.

## Algorithms and reasoning

- Big-O, space complexity, amortized analysis, and the effect of constants, allocation, cache locality, and I/O.
- Sorting, binary search, two pointers, sliding windows, prefix sums, recursion, backtracking, greedy algorithms, and dynamic programming.
- BFS, DFS, shortest paths, topological sorting, cycle detection, connected components, and union-find.
- Correctness: loop invariants, boundary cases, integer overflow, nullability, and choosing readable solutions over clever ones.

## Practical use

- Know the performance characteristics of your language's standard collections, including their memory behavior, ordering, mutability, and concurrency guarantees.
- Measure when performance matters with an appropriate benchmark tool or realistic load test; avoid guessing.
