---
title: "Cloud, Containers & Delivery"
---

- Linux: processes, signals, permissions, cgroups, namespaces, filesystems, sockets, CPU/memory limits, and common shell/networking commands.
- Docker: images/layers, multi-stage builds, minimal non-root images, immutable configuration, registries, health checks, and image scanning.
- Kubernetes: pods, deployments, services, ingress, config/secrets, requests/limits, probes, autoscaling, jobs, RBAC, namespaces, and rollout failure modes.
- Cloud fundamentals: regions/AZs, VPCs/subnets, routing, load balancers, managed databases, object storage, IAM, KMS, logging, and cost tagging.
- Delivery: CI, artifact promotion, infrastructure as code, environment parity, database migrations, canary/blue-green/rolling releases, feature flags, and automated rollback.
- Treat configuration and infrastructure as versioned, reviewed code. Keep credentials out of repositories and production access narrowly scoped.
